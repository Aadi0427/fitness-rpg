# ⚔️ Fitness RPG

A full-stack fitness application that turns real-world workouts into an RPG-style progression system.

Complete workouts, earn XP, level up your character, improve stats, complete quests, and unlock achievements.

---

## 🎮 Project Concept

Fitness RPG combines fitness tracking with RPG game mechanics.

The core idea is:

Workout → XP → Level Up → Stats → Quests → Achievements

The goal is to make fitness more engaging by giving users a sense of progression.

## 📈 Progression System

Players earn XP by completing fitness activities.

Example:

| Activity | XP |
|---|---:|
| 50 Push-ups | +50 XP |
| 30 min Running | +75 XP |

Level requirements increase as the player progresses.

Example:

Level 1 → 100 XP  
Level 2 → 150 XP  
Level 3 → 225 XP  
Level 4 → 337 XP
